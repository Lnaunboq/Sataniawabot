# SataniawaBot

Utilise les commandes ci-dessous dans Discord en commençant par `>`.
Les arguments entre `<…>` sont obligatoires ; ceux entre `[…]` sont facultatifs.
Remplace-les par ton texte ou ton choix, sans saisir les chevrons ni les crochets.

## Commandes

| Commande | Ce qu’elle fait | Exemple |
| --- | --- | --- |
| `>help` | Affiche les commandes disponibles | `>help` |
| `>help <commande>` | Explique comment utiliser une commande | `>help music` |
| `>jp <texte>` | Traduit un texte en japonais et affiche ton nom | `>jp Bonjour tout le monde !` |
| `>ko <texte>` | Traduit un texte en coréen et affiche ton nom | `>ko Bonjour tout le monde !` |
| `>sushi` | Affiche une image de sushi | `>sushi` |
| `>music [playlist]` | Partage un titre choisi au hasard dans une playlist | `>music rock` |
| `>music list` | Affiche les playlists disponibles | `>music list` |
| `>valheim` ou `>valheim status` | Indique si le serveur Valheim est allumé ou éteint | `>valheim` |
| `>valheim player` ou `>valheim players` | Affiche le dernier nombre de joueurs connu, les noms disponibles et l’heure de mesure | `>valheim player` |

## Musique

Utilise `>music` pour choisir un titre dans la playlist `default`.
Pour choisir une autre playlist, indique son nom : `>music weeb`, `>music sussy`
ou `>music rock`. Retrouve la liste avec `>music list`.
La commande partage le titre, l’artiste et un lien pour l’écouter.

## Images de sushi

Utilise `>sushi` pour recevoir une image de sushi. La même image peut revenir
lors de plusieurs demandes.

## Serveur Valheim

Utilise `>valheim` pour connaître l’état du serveur. Lorsqu’il est indiqué allumé,
il peut encore être en cours de démarrage.

Utilise `>valheim player` pour consulter les dernières informations sur les joueurs.
Elles sont actualisées environ toutes les dix minutes et peuvent donc différer de
la situation au moment de ta demande. L’heure affichée est celle du serveur.
Les noms ne sont pas toujours disponibles.

Pour consulter l’aide détaillée, utilise `>help valheim player`.
